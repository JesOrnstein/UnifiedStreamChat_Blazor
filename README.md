UnifiedStreamChat

UnifiedStreamChat is a web application developed with ASP.NET Core and Blazor that combines live chat messages from multiple streaming platforms into one unified chat interface.

The application currently supports Twitch, YouTube Live, and Kick, allowing users to connect their accounts and view messages from different platforms in the same place.

Features

- Connect Twitch, YouTube, and Kick accounts
- Display messages from multiple platforms in one unified chat
- OAuth authentication for each streaming platform
- Support for multiple users
- Platform identification for each message
- Username and timestamp display
- Twitch badges
- YouTube roles such as Member, Moderator, and Owner
- Connect and disconnect platforms individually
- Real-time chat messages

Used

- C# – Main programming language
- ASP.NET Core – Backend and web application framework
- Blazor Server – Interactive web interface
- Twitch API – Twitch authentication and chat integration
- YouTube Data API – YouTube authentication and live chat integration
- Kick API / KickLib – Kick authentication and chat integration
- OAuth 2.0 – Authentication with streaming platforms
- HTML & CSS – Interface design and styling
- Session Management – Separates connections between different users

About

The goal of UnifiedStreamChat is to make it easier for streamers to manage communities across multiple streaming platforms. Instead of monitoring several separate chat windows, messages from Twitch, YouTube, and Kick can be viewed together in a single interface.

The project demonstrates API integration, OAuth authentication, real-time communication, multi-user session management, and web development using ASP.NET Core and Blazor.
